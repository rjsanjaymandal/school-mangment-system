# Skill Context

This project is a **School Management System (SMS)** built with modern web technologies.

The AI must use the following technology stack.

## Frontend
- Next.js 14 (App Router)
- React
- TypeScript
- Tailwind CSS
- Shadcn UI

Skills required:
- component architecture
- server components
- client components
- layouts
- form handling
- API integration

Libraries:
- React Hook Form
- Zod validation
- TanStack Table
- Recharts

## Backend

Backend is handled by Supabase.

Services used:
- Supabase Auth
- PostgreSQL database
- Supabase Storage
- Row Level Security (RLS)

The AI must implement:
- secure CRUD operations
- server actions
- API interaction with Supabase

## Authentication

Authentication system requirements:

- single login page
- admin created accounts
- password setup email
- secure sessions
- role based login

Roles supported:

admin  
teacher  
student  
parent

## Deployment

Frontend hosting:
- Vercel

Backend hosting:
- Supabase Cloud
