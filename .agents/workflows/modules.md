# System Modules

The School Management System must be built using modular architecture.

Each module should be independent and reusable.

---

## Core Modules

### User Management
Handles authentication and roles.

Features:
- user login
- role assignment
- account activation
- password reset

Roles supported:
- admin
- teacher
- student
- parent

---

### Student Management

Features:
- create student account
- assign class
- view student profile
- track academic records

---

### Teacher Management

Features:
- create teacher accounts
- assign subjects
- assign classes
- teacher profile management

---

### Class Management

Features:
- create classes
- assign class teacher
- manage student list
- timetable support

---

### Subject Management

Features:
- define subjects
- assign subject teachers
- link subjects to classes

---

### Attendance Module

Features:
- mark attendance
- view attendance reports
- teacher attendance management
- student attendance dashboard

---

### Exam Module

Features:
- create exams
- upload marks
- generate report cards
- exam schedule

---

### Fee Management

Features:
- define fee structures
- track payments
- generate invoices
- payment history

---

### Notification Module

Features:
- system announcements
- teacher notifications
- parent notifications
- email alerts
