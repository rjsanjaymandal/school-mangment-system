# Product Requirements

This project is a **School Management System**.

The goal is to build a platform where schools can manage:

- students
- teachers
- classes
- exams
- attendance
- fees

---

## Admin Features

- create student accounts
- create teacher accounts
- assign classes
- view analytics
- manage school data

---

## Teacher Features

- mark attendance
- upload grades
- manage class students
- view timetable

---

## Student Features

- view attendance
- view results
- view timetable
- receive notifications

---

## Parent Features

- view child progress
- view attendance
- receive notifications
